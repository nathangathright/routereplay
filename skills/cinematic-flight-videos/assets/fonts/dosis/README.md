# Dosis

Rounded sans-serif used for the optional flight telemetry overlay. The unmodified
variable font is bundled with its SIL Open Font License; it requires no download
or system font installation when rendering.

Source: [Google Fonts Dosis](https://github.com/google/fonts/tree/main/ofl/dosis).
Authors: The Dosis Project Authors. Retrieved 2026-10-20.

This is a freely distributable approximation of the rounded industrial lettering
requested for the overlay, not the commercial DIN Round typeface. Set
`FLIGHT_TELEMETRY_FONT` to a locally licensed TrueType/OpenType file to substitute
another typeface. Airport split-flap lettering keeps its existing font.
